# Security Policy

RitualDev-Lab prioritizes the security and integrity of **PromptShield** and the developer ecosystem.

## Supported Versions
| Branch / Release | Supported |
| :--- | :--- |
| Latest `main` | :white_check_mark: |
| Active Releases | :white_check_mark: |

## Reporting Vulnerabilities
Please do **NOT** report security vulnerabilities via public GitHub issues.

Send security reports privately to:
**security@ritualdev.in**
or use GitHub Private Vulnerability Reporting if enabled.

### Response Timelines
- **Initial Acknowledgment**: Within 24 hours.
- **Triage & Assessment**: Within 48 hours.
- **Fix & Advisory**: Coordinated release within 7-14 days.
